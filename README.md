# GREYSON SHILOH

An interactive planting map and field record for a one-acre food forest.

## Website

[greysonshiloh.com](https://greysonshiloh.com)

`index.html` is the complete standalone website (Build 141). Open it in a browser to use the map locally. Plant records, reference photographs, and map imagery are embedded; no installation or build step is required.

The map supports individual plant selection, grouped planting records, seasonal browsing, and reference information. In edit mode, export changes to keep a saved copy.

## Publishing

The site is served through GitHub Pages. Update the root `index.html` to publish a new version. Keep `CNAME`, which preserves the custom domain, and `.nojekyll` for direct static publishing. Verify the Pages deployment and live site after updates.

Plant image credits and references are included within the website. Original image licenses continue to apply.

Earlier versions remain available in Git history; duplicate HTML exports are not needed in the published directory.
